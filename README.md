# Country Drill

Learn every country region by region: study a region, quiz it (click on the map or type the name), mark it as learned, then quiz all your learned regions together.

Live: https://e18cheng.github.io/country-drill/

Single static page (`index.html`); map data from [world-atlas](https://github.com/topojson/world-atlas) / Natural Earth, loaded from jsDelivr. Progress is saved in your browser's localStorage. Regions are defined in `REGION_DEFS` at the top of the script.
